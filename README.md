# Jogo-de-Cartas
Jogo da memória feito com HTML, CSS e JavaScript puro, onde os pares combinam termos de JS (fetch, async/await, localStorage...) com o que cada um faz. Cartas que viram com animação, cronômetro, contador de jogadas e melhor tempo salvo no navegador. Ótimo para revisar a matéria jogando.
